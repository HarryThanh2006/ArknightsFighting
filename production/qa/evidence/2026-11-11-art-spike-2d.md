## Pipeline cost (measured from this work)

Adding **one animation for an existing sim state** (e.g. a second idle):
1. Add a `[anim]` section with tick ranges to `frames.cfg` (1 file, ~4 lines).
2. Draw the strip `<char>_<anim>.png`, N × 512×384 (1 file).
3. Open the editor or run `--import` once (Godot writes `.png.import`).

Adding **an animation for a new state** (e.g. jump): the above, plus one
name in `CharacterSprite.ANIMS` and one line in `_pick`, plus any new read-only
`SimView` accessor (2 GDScript files). Adding **a new character**: a folder with
`frames.cfg` + 7 strips; `SPRITE_DIR` / `SPRITE_CHAR` select it (per-player
selection arrives with Operator Definitions).

Generating the blockout + templates: one command, < 5 s. Changing move data
frames: re-run the generator; the frames.cfg consistency test fails if the
ranges no longer tile the move or isolate its active window.

## Hand-drawing estimate per animation — ESTIMATE, NOT A MEASUREMENT

No drawing was done in this spike, so the spike's main question (cost per
animation) is answered only as a range to be replaced by a timed trial. At
512×384 per drawing, character ~307 px tall, flat colour + 3 px outline,
2–3 value shades (art bible §5.2), drawn over the template:

| Artist | Per drawing | Light (6) | Heavy (7) | One character (32) |
|---|---|---|---|---|
| Experienced 2D game artist | 1–2 h | 6–12 h | 7–14 h | 32–64 h |
| Hobbyist / learning | 2–4 h | 12–24 h | 14–28 h | 64–128 h |

Tier 0 lists ~23 animations across its characters (systems-index); at ~4.5
drawings each that is ~100 drawings, i.e. roughly 100–200 h (experienced) or
200–400 h (hobbyist), before effects art. **Recommended next step:** time one
real hand-drawn Light (6 drawings) over `template/guard_blockout_light_template.png`
and replace this table with the measured number.
